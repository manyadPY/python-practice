### تمرین ۱

دو متغیر زیر را ایجاد کنید:

a = 15

b = 5

نتیجه موارد زیر را چاپ کنید:

    جمع
    تفریق
    ضرب
    تقسیم


### پاسخ

```python

a = 15
b = 5

print("+", a + b)
print("-", a - b)
print("*", a * b)
print("/", a / b)

```
