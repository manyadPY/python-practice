### تمرین ۱

دو متغیر زیر را ایجاد کنید:

a = 15

b = 5

نتیجه موارد زیر را چاپ کنید:

    جمع
    تفریق
    ضرب
    تقسیم


### پاسخ

```python

a = 15
b = 5

print("+", a + b)
print("-", a - b)
print("*", a * b)
print("/", a / b)

```

### تمرین ۲

یک متغیر به نام score با مقدار 80 ایجاد کنید.

با استفاده از یکی از عملگر های انتساب، مقدار آن را 10 واحد افزایش دهید.

سپس نتیجه را نمایش دهید.

### پاسخ

```python

score = 80
score += 10

print(score)

```

age = 36
