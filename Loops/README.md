### تمرین ۱ — چاپ اعداد

با استفاده از حلقه for، اعداد ۱ تا ۱۰ را چاپ کنید.

### پاسخ:

```python

for i in range(1,11):
    print(i)

```

---



### تمرین ۲ — چاپ اعداد به صورت معکوس

با استفاده از حلقه for، اعداد ۱۰ تا ۱ را به صورت نزولی چاپ کنید.

### پاسخ:

```python

for i in range(10, 1):
     print(i)

```
